## Quick Start with Moises PC

1. **Get Moises PC** — Grab the portable `.exe` (no installation required) or the installer version.
2. **Launch** — Double-click `Moises_PC.exe`. The main window opens in under 2 seconds.
3. **Load your first track** — Drag any MP3, M4A, FLAC, or WAV file into **Moises PC**.
4. **Separate stems** — Click "Vocal Remover" → choose 2, 4, or 5 stems (vocals, drums, bass, piano, other). **Moises PC** processes in 10–30 seconds.
5. **Adjust pitch and tempo** — Move the pitch slider up or down by 12 semitones. Change BPM from 50% to 200% in **Moises PC**.
6. **Export** — Select which stems you want. **Moises PC** saves them as high-quality WAV or MP3 files.
7. **Work normally** — **Moises PC** activates automatically whenever you need vocal isolation or key shifting.

## Understanding Moises PC Core Components

**Moises PC** is not just another audio player. It combines several essential AI audio tools:

- **AI Stem Separator** — Uses deep learning to split any song into up to 5 independent tracks.
- **Vocal Remover / Isolator** — Remove voices completely or keep only the vocals with **Moises PC** precision.
- **Pitch Shifter** — Change key from -12 to +12 semitones without affecting tempo.
- **Time Stretcher** — Slow down or speed up tracks from 50% to 200% without pitch distortion.
- **Smart Metronome** — Automatically detects song BPM and provides visual/audio beats.
- **Multi-format support** — MP3, WAV, FLAC, M4A, OGG, AAC, and more in **Moises PC**.
- **Batch processing** — Queue multiple songs for stem separation overnight.
- **Portable mode** — Run **Moises PC** directly from a USB drive on any Windows PC (no admin rights needed).

All these work together seamlessly in **Moises PC**. You never need to switch between separate audio applications.
